Funzionalità

TUTTO QUELLO
CHE TI SERVE

01 🔍
Ricerca avanzata

Full-text su titolo, autore e sinossi. Filtri per anno, tag e preferiti. Risultati istantanei.

02 ★
Preferiti

Segna gli albi preferiti con un click. Badge visivo in griglia e filtro dedicato.

03 🏷
Tag personali

Organizza la collezione con tag liberi. Autocompletamento e filtro rapido dalla home.

04 📝
Note

Note personali per ogni albo salvate in automatico. Non perdi mai un appunto.

05 ⚡
Scraper automatico

Scarica metadati e copertine da diabolik.it. Riprende dall'ultimo albo processato, rate-limited.

06 🐳
Docker ready

Un docker compose up e sei operativo. DB e copertine persistono sul filesystem host.

Installazione

AVVIO
RAPIDO

#scarica ed avvia
$docker compose up -d
 
#apri http://localhost:8080
#Impostazioni → Avvia refresh per scaricare gli albi

DB e copertine persistono tramite volumi Docker sul filesystem host.
Aggiornamento: docker pull abeggi/diabolik-archive:latest

$git clone https://github.com/abeggi/diabolik
$cd diabolik
$python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
 
#avvia webapp
$cd diabolik-archive/webapp && ../.venv/bin/python main.py
 
#scarica gli albi (separatamente)
$cd diabolik-archive && ../.venv/bin/python scraper.py

Python 3.10+ richiesto.
